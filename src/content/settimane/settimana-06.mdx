`GROUP BY` raggruppa le righe con lo stesso valore e ti permette di calcolare un totale per gruppo. `WHERE` filtra **prima** di raggruppare, `HAVING` filtra **dopo**.

Una **JOIN** collega due tabelle attraverso una colonna in comune. Con `INNER JOIN` tieni solo le righe che trovano corrispondenza; con `LEFT JOIN` tieni tutte quelle della prima tabella.

```sql
SELECT p.regione,
       COUNT(*)             AS comuni,
       SUM(s.num_scuole)    AS scuole
FROM 'popolazione.csv' AS p
LEFT JOIN 'scuole.csv' AS s ON s.codice_istat = p.codice_istat
GROUP BY p.regione
HAVING COUNT(*) > 100
ORDER BY scuole DESC;
```

## La chiave giusta

Collega le tabelle con un **codice**, mai con un nome. "Reggio Emilia" e "Reggio nell'Emilia" sono lo stesso comune, ma il codice ISTAT è uno solo.

## DISTINCT e il conteggio dei valori unici

`DISTINCT` toglie le righe duplicate dal risultato. Dentro un conteggio, `COUNT(DISTINCT colonna)` conta quanti valori diversi ci sono.

```sql
SELECT regione,
       COUNT(*)                  AS righe,
       COUNT(DISTINCT provincia) AS province
FROM 'comuni.csv'
GROUP BY regione;
```

## L'errore più comune con le JOIN

Se nella seconda tabella la chiave compare più volte, ogni riga della prima viene duplicata e i totali crescono senza motivo. Prima di una JOIN controlla che la chiave sia unica:

```sql
SELECT codice_istat, COUNT(*) AS n
FROM 'scuole.csv'
GROUP BY codice_istat
HAVING COUNT(*) > 1;   -- se esce qualcosa, aggrega prima di unire
```
