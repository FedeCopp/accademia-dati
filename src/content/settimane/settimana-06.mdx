  linguaggio: sql

- id: s06-left-join
  titolo: Nessun comune lasciato indietro
  consegna: Per **ogni** comune mostra `comune` e `num_scuole`, prendendo le scuole da `scuole.csv` (collega i file con `codice_istat`). Se un comune non compare in `scuole.csv`, `num_scuole` deve valere 0.
  linguaggio: sql
  dataset:
  - comuni.csv
  - scuole.csv
  iniziale: |
    SELECT c.comune, s.num_scuole
    FROM 'comuni.csv' AS c
    JOIN 'scuole.csv' AS s ON s.codice_istat = c.codice_istat;
  soluzione: |
    SELECT c.comune,
           COALESCE(s.num_scuole, 0) AS num_scuole

`GROUP BY` raggruppa le righe con lo stesso valore e ti permette di calcolare un totale per gruppo. `WHERE` filtra **prima** di raggruppare, `HAVING` filtra **dopo**.

Una **JOIN** collega due tabelle attraverso una colonna in comune. Con `INNER JOIN` tieni solo le righe che trovano corrispondenza; con `LEFT JOIN` tieni tutte quelle della prima tabella.

```sql
SELECT p.regione,
       COUNT(*)             AS comuni,
       SUM(s.num_scuole)    AS scuole
FROM 'popolazione.csv' AS p
LEFT JOIN 'scuole.csv' AS s ON s.codice_istat = p.codice_istat
GROUP BY p.regione
HAVING COUNT(*) > 100
ORDER BY scuole DESC;
```

## Le funzioni di aggregazione

| Funzione | Cosa calcola | Nota |
| --- | --- | --- |
| `COUNT(*)` | numero di righe | conta anche le righe con valori mancanti |
| `COUNT(colonna)` | righe con un valore | ignora i `NULL` |
| `SUM(colonna)` | somma | |
| `AVG(colonna)` | media | ignora i `NULL` |
| `MIN` / `MAX` | valore più piccolo e più grande | funzionano anche su testi e date |

Tutte ignorano i valori mancanti, tranne `COUNT(*)`. Per questo `AVG` può dare un risultato diverso da `SUM / COUNT(*)`.
## DISTINCT e il conteggio dei valori unici

`DISTINCT` toglie le righe duplicate dal risultato. Dentro un conteggio, `COUNT(DISTINCT colonna)` conta quanti valori diversi ci sono.

```sql
SELECT regione,
       COUNT(*)                  AS righe,
       COUNT(DISTINCT provincia) AS province
FROM 'comuni.csv'
GROUP BY regione;
```

## L'errore più comune con le JOIN

Se nella seconda tabella la chiave compare più volte, ogni riga della prima viene duplicata e i totali crescono senza motivo. Prima di una JOIN controlla che la chiave sia unica:

```sql
SELECT codice_istat, COUNT(*) AS n
FROM 'scuole.csv'
GROUP BY codice_istat
HAVING COUNT(*) > 1;   -- se esce qualcosa, aggrega prima di unire
```
