Chi lavora con i dati passa la giornata tra tre strumenti: un **editor** dove scrive codice, un **terminale** dove lo esegue e **Git**, che tiene traccia di ogni modifica.

Git salva delle istantanee del tuo progetto, chiamate *commit*. Ogni commit ha un messaggio che spiega cosa hai cambiato. GitHub è il sito dove pubblichi questi progetti: diventa il tuo portfolio.

```bash
git init                 # trasforma la cartella in un repository
git add README.md        # prepara il file per il commit
git commit -m "Primo giorno: obiettivi del percorso"
git push                 # pubblica su GitHub
```

## Perché un diario pubblico

Scrivere tre righe a fine settimana ti obbliga a capire cosa hai imparato davvero. Dopo un anno avrai una cronologia che mostra la tua crescita meglio di qualsiasi certificato.

> Consiglio: blocca in calendario le tre sessioni settimanali come fossero appuntamenti. La costanza conta più dell'intensità.
