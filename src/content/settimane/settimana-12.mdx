## Teoria in breve

Il README è la parte del progetto che verrà letta di più. Chi lo apre deve capire in trenta secondi la domanda, la risposta e come riprodurre il lavoro.

## Schema del README

```markdown
# Titolo che contiene la risposta

## La domanda
Una frase.

## In breve
Tre punti con i risultati principali e il grafico più importante.

## Dati
Fonti, data di download, licenza, limiti.

## Come riprodurre
pip install -r requirements.txt
python src/download.py && python src/pulizia.py

## Cosa farei dopo
```
