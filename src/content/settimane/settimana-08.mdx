- id: s08-groupby
  titolo: Incasso per regione
  consegna: 'Aggiungi a `vendite` la colonna `incasso` (quantità per prezzo unitario). Poi crea `incasso_regione`: l''incasso totale per regione, ordinato dal più alto al più basso.'
  linguaggio: python
  dataset:
  - vendite.csv
  iniziale: |
    import pandas as pd

    vendite = pd.read_csv("vendite.csv")

    # 1. colonna incasso
    # 2. incasso_regione
    incasso_regione = None
    print(incasso_regione)
  soluzione: |
    import pandas as pd

    vendite = pd.read_csv("vendite.csv")
    vendite["incasso"] = vendite["quantita"] * vendite["prezzo_unitario"]

    incasso_regione = (vendite.groupby("regione")["incasso"]
                              .sum()
                              .sort_values(ascending=False))
    print(incasso_regione)
  test:
  - codice: |
      import pandas as _pd
      assert 'incasso' in vendite.columns, 'manca la colonna incasso in vendite'
    messaggio: Manca la colonna `incasso` in `vendite`
  - codice: |
      _v = _pd.read_csv('vendite.csv')
      _v['i'] = _v['quantita'] * _v['prezzo_unitario']
      _ref = _v.groupby('regione')['i'].sum()
      assert incasso_regione is not None, 'incasso_regione è ancora None'
      _got = _pd.Series(incasso_regione.squeeze() if isinstance(incasso_regione, _pd.DataFrame) else incasso_regione)
      assert set(_got.index) == set(_ref.index), f'regioni trovate: {sorted(_got.index)}'
      for _k in _ref.index:
          assert abs(float(_got[_k]) - float(_ref[_k])) < 1e-6, f'{_k}: {float(_got[_k]):.2f} invece di {float(_ref[_k]):.2f}'
    messaggio: I totali per regione non sono giusti
  - codice: |
      _vals = [float(x) for x in _got.values]
      assert _vals == sorted(_vals, reverse=True), 'le regioni non sono in ordine decrescente'
    messaggio: Ordina dal più alto al più basso con `sort_values(ascending=False)`
  suggerimenti:
  - 'Una colonna nuova si crea così: `vendite["incasso"] = vendite["quantita"] * vendite["prezzo_unitario"]`.'
  - '`groupby("regione")["incasso"].sum()` e poi `.sort_values(ascending=False)`.'

Un **DataFrame** è una tabella in memoria: colonne con un nome e un tipo, righe con un indice. Quasi ogni operazione SQL ha un equivalente in pandas.

| SQL | pandas |
| --- | --- |
| `WHERE regione = 'Lazio'` | `df[df["regione"] == "Lazio"]` |
| `GROUP BY regione` + `SUM` | `df.groupby("regione")["valore"].sum()` |
| `ORDER BY valore DESC` | `df.sort_values("valore", ascending=False)` |
| `JOIN` | `df.merge(altro, on="codice")` |

```python
import pandas as pd

df = pd.read_csv("comuni.csv", sep=";", decimal=",")
top = (df[df["regione"] == "Lombardia"]
         .sort_values("popolazione", ascending=False)
         .head(10))
print(top[["comune", "popolazione"]])
```
