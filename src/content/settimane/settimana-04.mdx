## Teoria in breve

Ogni comando fa una cosa sola, e la **pipe** `|` passa l'output di un comando come input al successivo. Così componi operazioni complesse da pezzi semplici.

```bash
wc -l dataset.csv                          # quante righe
head -n 5 dataset.csv                      # prime 5 righe
cut -d ';' -f 3 dataset.csv | sort | uniq -c | sort -rn | head
#   colonna 3  →  ordina  →  conta i valori  →  i più frequenti
grep -i "milano" dataset.csv | wc -l       # righe che contengono "milano"
```

## Su Windows

Installa **WSL** (Windows Subsystem for Linux) con Ubuntu: hai un vero terminale Linux senza cambiare sistema. Su Mac il terminale è già compatibile.
