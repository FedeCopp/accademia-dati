SQL è **dichiarativo**: descrivi il risultato che vuoi, non i passaggi per ottenerlo. Una query si legge quasi come una frase.

```sql
SELECT comune, popolazione        -- quali colonne
FROM 'comuni.csv'                 -- da quale tabella (DuckDB legge il CSV)
WHERE regione = 'Lombardia'       -- quali righe
ORDER BY popolazione DESC         -- in che ordine
LIMIT 10;                         -- quante
```

## Perché DuckDB

Non devi installare un server né importare nulla: punti un file CSV o Parquet e lo interroghi. È lo strumento più rapido per esercitarti con SQL su dati veri, ed è usato anche in produzione.

## Domande da cui partire

- Quali sono i 10 valori più alti di una colonna numerica?
- Quante righe soddisfano una certa condizione?
- Quali righe hanno un valore mancante (`IS NULL`)?

## Colonne calcolate e condizioni combinate

Puoi creare colonne nuove direttamente nella query, dando loro un nome con `AS`. Quando combini `AND` e `OR`, usa sempre le parentesi: `AND` viene valutato prima di `OR`, e senza parentesi la query fa qualcosa di diverso da quello che pensi.

```sql
SELECT comune,
       popolazione,
       superficie_km2,
       popolazione / superficie_km2 AS densita      -- colonna calcolata
FROM 'comuni.csv'
WHERE regione = 'Puglia'
  AND (popolazione > 50000 OR superficie_km2 > 300); -- parentesi!
```

## Dialetti SQL: se un video usa SQL Server

Il linguaggio è lo stesso ovunque, ma ogni database ha qualche parola sua. I video consigliati usano SQL Server, qui usi DuckDB:

| Cosa vuoi fare | SQL Server | DuckDB e PostgreSQL |
| --- | --- | --- |
| Prime 10 righe | `SELECT TOP 10 ...` | `... LIMIT 10` |
| Data di oggi | `GETDATE()` | `current_date` |
| Unire testi | `nome + ' ' + cognome` | `nome \|\| ' ' \|\| cognome` |
| Nomi con spazi | `[nome colonna]` | `"nome colonna"` |

Se una query dei video non funziona, quasi sempre la differenza è in questa tabella.
