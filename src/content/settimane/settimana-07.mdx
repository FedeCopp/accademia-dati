Una **CTE** (`WITH nome AS (...)`) dà un nome a un risultato intermedio. Le query lunghe diventano una sequenza di passaggi che si leggono dall'alto in basso.

Una **window function** calcola un valore guardando le righe vicine, senza ridurle a una sola come fa `GROUP BY`. È lo strumento che separa chi sa SQL da chi lo usa davvero.

```sql
WITH mensile AS (
  SELECT date_trunc('month', data) AS mese,
         SUM(importo)              AS totale
  FROM 'vendite.csv'
  GROUP BY 1
)
SELECT mese,
       totale,
       totale - LAG(totale) OVER (ORDER BY mese)  AS variazione,
       SUM(totale) OVER (ORDER BY mese)           AS progressivo
FROM mensile
ORDER BY mese;
```

## Le quattro da ricordare

| Funzione | A cosa serve |
| --- | --- |
| `ROW_NUMBER()` | numerare le righe, per esempio per tenere solo la più recente |
| `RANK()` | classifiche con eventuali pari merito |
| `LAG()` / `LEAD()` | confrontare con la riga precedente o successiva |
| `SUM() OVER` | totali progressivi e medie mobili |

## Un metodo per le query complesse

Davanti a una domanda difficile non scrivere tutto in una volta. Procedi per passi, una CTE per ciascuno, e controlla il risultato a ogni passo:

1. Scrivi la domanda in italiano, con l'unità di misura (per mese? per cliente?).
2. Elenca le tabelle che servono e le chiavi che le collegano.
3. Filtra le righe che ti interessano.
4. Calcola le aggregazioni.
5. Aggiungi classifiche o confronti con le window function.

## Confrontare righe della stessa tabella

Per confrontare una riga con la precedente usa `LAG`. Per confronti più liberi puoi unire la tabella con sé stessa (self-join), dandole due alias:

```sql
-- Prezzo di oggi contro quello di sette giorni prima
SELECT oggi.data, oggi.prezzo, prima.prezzo AS prezzo_7gg_fa
FROM 'prezzi.csv' AS oggi
LEFT JOIN 'prezzi.csv' AS prima
       ON prima.data = oggi.data - INTERVAL 7 DAY;
```
