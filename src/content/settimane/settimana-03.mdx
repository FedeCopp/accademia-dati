Una **funzione** dà un nome a un pezzo di logica, così puoi riusarla e testarla. Un file **CSV** è una tabella salvata come testo: ogni riga un record, i valori separati da virgole (o, nei dati italiani, spesso da punto e virgola).

```python
import csv

def leggi(percorso):
    with open(percorso, encoding="utf-8") as f:
        return list(csv.DictReader(f, delimiter=";"))

righe = leggi("dataset.csv")
print(len(righe), "righe")
print("Colonne:", list(righe[0].keys()))
```

## Attenzione ai dati italiani

- Il separatore è spesso `;` e i decimali usano la virgola: `"3,5"` va convertito con `float("3,5".replace(",", "."))`.
- Alcuni file usano la codifica `latin-1` invece di `utf-8`. Se vedi caratteri strani nelle lettere accentate, prova a cambiarla.
- Usa `try` ed `except` per gestire le righe con valori mancanti invece di far fallire tutto lo script.
