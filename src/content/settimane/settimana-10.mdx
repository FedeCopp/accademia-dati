  soluzione: |
    import pandas as pd
    import matplotlib.pyplot as plt

    vendite = pd.read_csv("vendite.csv", parse_dates=["data"])
    vendite["incasso"] = vendite["quantita"] * vendite["prezzo_unitario"]
    vendite["mese"] = vendite["data"].dt.month

    mensile = vendite.groupby("mese")["incasso"].sum()
    ax = mensile.plot(kind="line", marker="o", color="#0f766e")
    ax.set_title("Gennaio è il mese con l'incasso più alto")
    ax.set_ylabel("Euro")
    ax.set_xlabel("Mese")
    plt.tight_layout()
  test:
  - codice: |
      import matplotlib.pyplot as _plt
      assert _plt.get_fignums(), 'non hai creato nessun grafico'
      _ax = _plt.gcf().axes[0]
      assert len(_ax.get_lines()) >= 1, 'nel grafico non c\'è nessuna linea'
      assert len(_ax.get_lines()[0].get_xdata()) == 6, f'la linea ha {len(_ax.get_lines()[0].get_xdata())} punti, i mesi sono 6'
    messaggio: Serve una linea con un punto per ogni mese
  - codice: assert _ax.get_ylabel().strip() != '', 'manca l\'etichetta dell\'asse verticale'
    messaggio: Scrivi l'unità di misura sull'asse verticale con `ax.set_ylabel("Euro")`
  suggerimenti:
  - '`vendite.groupby("mese")["incasso"].sum()` dà un valore per mese.'
  - '`.plot(kind="line", marker="o")` disegna la linea; poi `ax.set_ylabel("Euro")`.'
---


Un grafico è una risposta a una domanda. Prima scegli la domanda, poi la forma.

| Domanda | Grafico |
| --- | --- |
| Chi è più grande? | barre orizzontali, ordinate |
| Come cambia nel tempo? | linea |
| C'è una relazione tra due misure? | dispersione |
| Come si distribuiscono i valori? | istogramma |

```python
import matplotlib.pyplot as plt

ax = df.groupby("mese")["totale"].sum().plot(kind="line", color="#0f766e")
ax.set_title("Le vendite calano da marzo")
ax.set_ylabel("Euro")
ax.spines[["top", "right"]].set_visible(False)
plt.tight_layout()
plt.savefig("vendite.png", dpi=150)
```

## Regole che valgono sempre

- Le barre partono da zero.
- Niente torte con più di tre fette e niente 3D.
- Un solo colore forte, per la cosa che vuoi far notare.
